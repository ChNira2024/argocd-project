=>Deploy microservices-tax-price-calculation project in kubernetes kind cluster using ArgoCD GitOps Tool.

=>Login ArgoCD with default username: admin and password niranjan@123
=>then go to setting->Repository->Connect with Repo->select Https->select project is "default"->
here copy your github base project url(https://github.com/ChNira2024/docker-k8s-deployment) ->then click connection

=>Then comes to application to create service ->click NEW APP ->enter any project name "tax-service"
=>Then select project name is "default" ->then check box auto-create namespace->then paste github repo(https://github.com/ChNira2024/docker-k8s-deployment)
->then paste the path means where actually .yml file is present...(microservices-tax-price-calculation/tax-service)->then select the branch(main)
->then select default namespace->then select cluster url(https://kubernetes.default.svc) this is default one->then create...
